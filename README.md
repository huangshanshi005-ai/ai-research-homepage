# AI Research Portfolio

一个现代简洁风格的个人主页网站，用于展示 AI 学习经历、科研项目、技术栈、获奖经历和联系方式。

## 启动步骤

1. 安装 Node.js 18 或更高版本。
2. 在项目根目录安装依赖：

   ```bash
   npm install
   ```

3. 启动本地开发服务器：

   ```bash
   npm run dev
   ```

4. 打开终端显示的本地地址，通常是：

   ```text
   http://localhost:5173
   ```

## 常用命令

```bash
npm run dev
npm run build
npm run preview
```

## 可替换内容

- `src/App.jsx`：修改个人简介、科研项目、技术栈、获奖经历和联系方式。
- `src/assets/research-hero.png`：替换首页背景图。
- `src/index.css` 与 `tailwind.config.js`：调整字体、颜色和全局风格。
